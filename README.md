# أداة المزامنة التلقائية بين تليجرام ومنصة FCIS Hub 🚀

هذه الأداة هي **Telegram Userbot** خفيف يعمل في الخلفية باستخدام رقم هاتفك الإضافي، لمراقبة مجتمع الدفعة على تليجرام، وسحب المحاضرات والسكاشن تلقائياً بمجرد نزولها في رسائل الفهرس (Overview)، ثم رفعها مباشرة إلى منصة **FCIS Hub** عبر الـ API الرسمي للمنصة وحفظها على **Google Drive**.

---

## 🌟 المميزات الرئيسية
1. **بدون الحاجة لصلاحيات أدمن:** يعمل كحساب طالب عادي داخل الكوميونيتي.
2. **سحب ذكي للملفات المعتمدة فقط:** يراقب فقط رسائل الـ Overview المجمعة لكل مادة، متجاهلاً أي رسائل أو أسئلة عشوائية في الشات.
3. **تسمية نظيفة ومنظمة:** يحول الرموز مثل `𝑳𝟎𝟏` و `𝑺𝟎𝟏` تلقائياً إلى:
   - محاضرات: `Lec 01`, `Lec 02`, ...
   - سكاشن: `Sec 01`, `Sec 02`, ...
4. **منع التكرار (Deduplication):** يحتفظ بسجل SQLite محلي للروابط التي تم سحبها مسبقاً، حتى لو قام المندوب بتعديل الرسالة لن يتم إعادة رفع الملفات القديمة.
5. **استخدام نفس الـ API الرسمي للمنصة:** الرفع يتم عبر `POST /api/materials/upload` بصلاحيات الأدمن، مما يعني:
   - فحص توقيع وامتداد الملف.
   - رفعه فورياً على Google Drive.
   - تسجيله في قاعدة البيانات كـ `Approved`.
   - إرسال إشعارات فورية للطلبة المشتركين في المادة.
6. **إشعارات تيليجرام للأدمن (اختياري):** إرسال رسالة خاصة على تليجرام فور نشر أي ملف بنجاح.

## 🛠️ خطوات التشغيل لأول مرة

### 1. استخراج مفاتيح تليجرام (خلال دقيقة واحدة):
1. افتح الموقع الرسمي لتليجرام: [my.telegram.org](https://my.telegram.org).
2. سجل برقم هاتفك الإضافي وضع كود التحقق.
3. اضغط على **API development tools**.
4. اكتب أي اسم للتطبيق (مثلاً `FcisSync`), وانسخ:
   - `api_id` (رقم)
   - `api_hash` (نص طويل)

### 2. تثبيت المكتبات المطلوبة:
تأكد من وجود Python 3.10+ ثم نفذ:
```bash
cd "d:\Abdulrhman\FCIS Hub\TOOLS\telegram_sync"
pip install -r requirements.txt
```

### 3. إعداد المتغيرات:
انسخ ملف `.env.example` إلى `.env`:
```bash
copy .env.example .env
```
افتح ملف `.env` واملأ البيانات:
```env
TG_API_ID=12345678
TG_API_HASH=your_api_hash_here
TG_PHONE=+201xxxxxxxxxx

TG_COMMUNITY=FCISCommunity29

FCIS_API_BASE=http://localhost:5000/api
FCIS_ADMIN_EMAIL=admin@fcishub.com
FCIS_ADMIN_PASSWORD=your_password_here

# اختياري: اكتب ID حسابك على تليجرام لاستلام إشعار بكل ملف يتم رفعه
ADMIN_TG_CHAT_ID=
```

### 4. ضبط خريطة المواد (config.json):
افتح `config.json` وضع أرقام الـ Topics الخاصة بالمواد:
```json
{
  "topics": {
    "17": {
      "subjectId": 1,
      "subjectName": "Web Development",
      "code": "WEB"
    }
  },
  "auto_resolve_by_name": true
}
```
*(ملاحظة: لو فعلت `auto_resolve_by_name: true`، السكريبت سيطابق اسم المادة المكتوب في رأس الرسالة مع اسم المادة في داتابيز FCIS Hub تلقائياً حتى لو لم تضع رقم الـ Topic!)*

### 5. تشغيل السكريبت:
```bash
python main.py
```
* **في أول تشغيل فقط:** سيطلب منك تليجرام كود التحقق المرسل لرقمك الإضافي. اكتبه، وسيتم إنشاء ملف جلسة `userbot_session.session` تلقائياً ولن يطلب الكود مرة أخرى أبداً.
* السكريبت سيبدأ بفحص الرسائل القديمة وسحب أي ملفات غير مسجلة، ثم يظل حياً (Real-time Listener) ينتظر أي تعديل أو رسالة جديدة.
